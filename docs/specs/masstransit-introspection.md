# What a built MassTransit state machine exposes

Spike for #504 (feature #503: an exporter that reads a **built** `MassTransitStateMachine<T>` instead of its source).
It answers which construct of the [diagram format](diagram-format.md) each MassTransit interface can read, so the
scope of the exporter is known before it is written. The throwaway project is
[`spikes/masstransit-introspection`](../../spikes/masstransit-introspection/README.md): it builds the six machines of
`samples/library` and a seventh (`Coverage.cs`) for the constructs they do not use, and dumps each through the three
interfaces. Run on MassTransit 8.5.12, 9.0.0 and 9.2.6 (one identical output for all three) and compiled against 8.0.0 (see
[Versions](#versions-frameworks-licenses)).

## The three interfaces

| Interface        | Call                                                                                                                                                      | What it gives                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Graph**        | `machine.GetGraph()` (`MassTransit.SagaStateMachine`)                                                                                                     | `Vertex` (`Title`, state or event, `IsComposite`) and `Edge` (`From`, `To`). Only state → event → state; no message types, no activities, no guards, and a branch (`If`) is a second edge from the same event with nothing telling the branches apart.                                                                                                                                                        |
| **Probe**        | `((IProbeSite)machine).GetProbeResult()`                                                                                                                  | A JSON-like tree: state → event (`name`, `dataType`) → `behavior` with `transition.toState`, `condition` (the branches), `catch`, `compositeEvent` (`property`, `event`, `flag`), `request` (`requestType`, `responseType`, `Timeout`), `event-ignored`. `send`, `publish`, `schedule`, `unschedule`, `then`, `thenAsync` and `cancelRequest` are **empty objects**: no message type.                         |
| **Visitor**      | `machine.Accept(StateMachineVisitor)`                                                                                                                     | Every state, event, behavior and activity in order. The activity types are generic, so the **message types are in the type arguments** (`SendActivity<TSaga, TData, TMessage>`, `PublishActivity`, `ScheduleActivity`, `RequestActivity<…, TRequest, TResponse>`). `TransitionActivity.ToState` is public; the schedule of `UnscheduleActivity` and `ScheduleActivity` (and so its delay) is a private field. |
| Plain properties | `Name`, `InstanceType`, `Initial`, `Final`, `States`, `Events`, `NextEvents(state)`, `IsCompositeEvent`, `Correlations` (on `MassTransitStateMachine<T>`) | The names; the type argument of `Event<T>`; the kind of correlation.                                                                                                                                                                                                                                                                                                                                          |

## The constructs

"Readable" means a program can get it from a built machine. Whether the format can show it is a separate question
(see [what stays a warning](#recommendation)).

| Construct (format)                         | Readable                   | Interface               | The code that reads it                                                                                                                                                                                                                                          |
| ------------------------------------------ | -------------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| States                                     | yes                        | plain                   | `machine.States` (`Initial` and `Final` included)                                                                                                                                                                                                               |
| Initial and final state                    | yes                        | plain                   | `machine.Initial`, `machine.Final`; `TransitionActivity.ToState == machine.Final` is `Finalize()`                                                                                                                                                               |
| Events and their message types             | yes                        | plain / visitor         | `machine.Events`; `ev.GetType().GetGenericArguments()[0]` of `Event<T>`; `Visit<TMessage>(Event<TMessage>, …)`                                                                                                                                                  |
| Transitions                                | yes                        | visitor (probe, graph)  | `TransitionActivity<T>.ToState` inside the behavior of an event under a state; probe `behavior.transition.toState`; graph edge event → state                                                                                                                    |
| `During` / `Initially`                     | yes                        | visitor                 | the `Visit(State, …)` the event sits under                                                                                                                                                                                                                      |
| `DuringAny`                                | **no**                     | none                    | MassTransit copies the handler into every state (and into `Initial`). It looks like the same `During` written for each state. Recoverable only as a heuristic: the same event with the same behavior in every non-final state                                   |
| `Ignore`                                   | yes                        | probe                   | `event-ignored` of a state. Not in the graph and not in the visitor (no activity)                                                                                                                                                                               |
| Guard of `When(E, filter)`                 | structure yes, text **no** | visitor / probe         | `ConditionActivity<TSaga, TMessage>` with a then and an else behavior (probe: `condition`). The filter is a compiled delegate: no source text. `When(E, filter)` and `When(E).If(filter, …)` build the same activities                                          |
| `If` / `IfElse` / `IfAsync`                | structure yes, text **no** | visitor / probe         | `ConditionActivity` (an `If` has an empty else: `EmptyBehavior`); the branch order is the order of the activities                                                                                                                                               |
| `Switch`                                   | not applicable             | –                       | does not exist in MassTransit 8 or 9 (`'EventActivityBinder' does not contain a definition for 'Switch'`)                                                                                                                                                       |
| `Send` with the message type               | yes                        | visitor                 | `SendActivity<TSaga, [TData,] TMessage>`: the last type argument. Probe: `send: {}`                                                                                                                                                                             |
| `Publish` with the message type            | yes                        | visitor                 | `PublishActivity<TSaga, [TData,] TMessage>`. Probe: `publish: {}`                                                                                                                                                                                               |
| `Request`                                  | yes                        | visitor + probe         | visitor: `RequestActivity<TSaga, TData, TRequest, TResponse>` and the events `<Name>.Completed` / `.Faulted` / `.TimeoutExpired`; probe: `request.requestType`, `responseType`, `Timeout`                                                                       |
| `Schedule`                                 | yes                        | visitor, private field  | `ScheduleActivity<TSaga, TData, TMessage>` for the message, the events `<Name>.Received` / `.AnyReceived` for the name; the delay is `Schedule.Settings.Delay` behind the private `_schedule` (reflection)                                                      |
| `Unschedule`                               | name via reflection        | visitor                 | `UnscheduleActivity<T>` has no type argument; the name is `_schedule.Name` (private field)                                                                                                                                                                      |
| `CompositeEvent`                           | yes                        | probe / graph / visitor | probe `compositeEvent` (`event`, `property`, `flag`); `machine.IsCompositeEvent(ev)`; graph `Vertex.IsComposite`; visitor `CompositeEventActivity` under each member event                                                                                      |
| `WhenEnter` / `WhenLeave`                  | yes                        | visitor / probe         | the trigger events `<State>.Enter` / `<State>.Leave` with their activities (`PublishActivity`, `SendActivity`, …)                                                                                                                                               |
| `BeforeEnter` / `AfterLeave`               | yes                        | visitor / probe         | the events `<State>.BeforeEnter` / `<State>.AfterLeave` (`Event<State>`)                                                                                                                                                                                        |
| `Finally`                                  | **no** (as such)           | visitor                 | becomes the event `Final.Enter`, which also lists under every state; the same as `WhenEnter(Final, …)`                                                                                                                                                          |
| `Catch` / `Fault`                          | yes (exception type)       | visitor / probe         | `CatchFaultActivity<TSaga, TException>` with its nested behavior; probe `catch.exceptionType`                                                                                                                                                                   |
| Routing slips                              | **events only**            | visitor                 | the built slip lives in the delegate of `Then` / `ThenAsync` (`AsyncActivity`, `ActionActivity`): its activities are not readable. `Event<RoutingSlipCompleted>` / `RoutingSlipFaulted` and their transitions are                                               |
| `Then` / `ThenAsync` code                  | no                         | –                       | `ActionActivity` / `AsyncActivity`: only that some code runs, not what it does                                                                                                                                                                                  |
| Correlation                                | kind only                  | plain                   | `Correlations` (`MessageEventCorrelation<TSaga, TMessage>`): `CorrelationIdMessageFilter` for `CorrelateById` / `CorrelateBy…SelectId`, the saga policy (`NewOrExisting` for the initial event). The expression `c => c.Message.OrderId` is a delegate: no text |
| Instance type                              | yes                        | plain                   | `machine.InstanceType` (`FullName` for the namespace)                                                                                                                                                                                                           |
| State property                             | yes                        | probe                   | `currentStateProperty` (`CurrentState`)                                                                                                                                                                                                                         |
| Saga class, namespace, contracts namespace | yes                        | plain                   | `machine.GetType()`, `message.Namespace`                                                                                                                                                                                                                        |
| `SetCompletedWhenFinalized`                | no                         | –                       | not visible in the three interfaces                                                                                                                                                                                                                             |

## Which warnings of the tree-sitter importer become readable

The importer (`packages/masstransit/src/import.ts`) warns about these. From a built machine:

| Warns today                                                                               | From a built machine                                                                                                                                                  |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `WhenLeave`, `BeforeEnter`, `AfterLeave`                                                  | **readable** (the events `<State>.Leave`, `.BeforeEnter`, `.AfterLeave` and their activities); the format has no place for them yet                                   |
| `Finally`                                                                                 | **readable only as** `Final.Enter`, not told apart from `WhenEnter(Final, …)`                                                                                         |
| `Fault`, `Catch`                                                                          | **readable** (`CatchFaultActivity`, exception type and nested transitions)                                                                                            |
| `WhenEnterAny`, `WhenLeaveAny`                                                            | readable as the same event under every state; not told apart from per-state ones                                                                                      |
| `OnUnhandledEvent`                                                                        | not checked (set outside the behaviors of a state)                                                                                                                    |
| `IfAsync`, `IfElseAsync`                                                                  | **readable** (the same `ConditionActivity` as `If`); the guard text stays unreadable                                                                                  |
| `Switch`                                                                                  | nothing to read: it does not compile                                                                                                                                  |
| Activities on the way into the final state (`Publish(…).Finalize()`)                      | **readable**: the activities and `TransitionActivity` to `Final` are in one behavior, in order                                                                        |
| Activities on a transition into a join                                                    | readable as activities of the event; the format cannot place them                                                                                                     |
| Other code in `Then(…)`                                                                   | still **not readable**                                                                                                                                                |
| A base class the parser cannot resolve, a name built in code, generic or partial machines | **readable**: the machine is built, so every name resolves                                                                                                            |
| Guard text (`context.Message.Outcome == "Approved"`)                                      | **worse than the source**: the importer keeps the text, a built machine has only a delegate (a PDB with sequence points could map it back to source lines; not tried) |

## Versions, frameworks, licenses

| Version                | Packages                                     | Lowest target framework                                   | License                                                                                                           | Spike result                                                                                                            |
| ---------------------- | -------------------------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 8.0.0                  | `MassTransit` (+ `MassTransit.Abstractions`) | `netstandard2.0`                                          | Apache-2.0                                                                                                        | **the reader does not compile unchanged**: `StateMachineVisitor` has other generic constraints than in 8.5.12 (not run) |
| 8.5.12 (last 8)        | same                                         | `net472`, `netstandard2.0`, `net8.0`, `net9.0`, `net10.0` | Apache-2.0                                                                                                        | reference output                                                                                                        |
| 9.0.0                  | same                                         | `net472`, `netstandard2.0`, `net8.0`, `net9.0`, `net10.0` | **commercial** ([Massient license](https://massient.com/license), per product line or organisation, subscription) | same output as 8.5.12                                                                                                   |
| 9.2.6 (latest checked) | same                                         | same as 9.0.0                                             | commercial                                                                                                        | same output as 8.5.12                                                                                                   |

The reading API (`Accept`, `GetGraph`, `GetProbeResult`, the activity types) gave the same output from 8.5.12 to 9.2.6; for 8.0.0 only the package metadata was checked.
A package that depends on `MassTransit` 9 brings the commercial license to everyone who installs it; one that depends
on 8.x stays Apache-2.0. The exporter therefore targets the 8.x API (Apache-2.0) unless #505 decides otherwise. The
lowest framework a package reading 8.x can target is `netstandard2.0`. 9.x ships the same five frameworks as 8.5.12.

## Recommendation

**The visitor is the basis**, read together with the plain properties of the machine.

- It is the only interface with the message types of `Send`, `Publish`, `Schedule` and `Request`, and with every
  event of every state (including `Enter`/`Leave`), `Catch` and the structure of `If`/`IfElse`.
- The probe adds what the visitor does not give without reflection: `Ignore`, the timeout of a request and the state
  property. It is a public, stable JSON tree; take these three from it.
- The graph is a subset of both and is not used.
- The private fields (`_schedule` for `Unschedule` and the delay of `Schedule`) are read by reflection, guarded by a test per
  supported version that fails when MassTransit renames them.

**What stays a warning:** `Then` / `ThenAsync` code and the routing slip itinerary (the slip's activities and their
compensation), the text of every guard and of every correlation expression, `DuringAny` (it can only be guessed),
`Finally` apart from `Final.Enter`, `OnUnhandledEvent`, `SetCompletedWhenFinalized`, and anything in the format with no
place for it (`WhenLeave`, `BeforeEnter`, `AfterLeave`, `Catch`).

**Follow-ups of #503:** #505 (ADR for a .NET library) records the license rule above and the lowest target framework;
#506 (solution, test project, CI) builds the test project against 8.x and checks 9.x in a second job; the exporter PBIs
read through the visitor with the probe for `Ignore`, request timeout and state property, and leave guard text empty
(an edge with a guard marker and no text) until a decision on PDB mapping.
