# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/GravionLabs/ariadne/security/advisories/new)
(Security tab, "Report a vulnerability"). Include the affected package or app (web, CLI, VS Code extension,
viewer), the version, and steps to reproduce.

You get an answer within a week. A confirmed vulnerability is fixed in the newest release and published as a
security advisory with credit to the reporter, unless you prefer otherwise.

## Supported versions

Only the newest release receives fixes.

## Scope

Ariadne documents sagas; it executes nothing. Relevant reports concern the apps and published packages (npm,
VS Code Marketplace, NuGet), the build and release workflows, and the dependency supply chain
(see [ADR 0019](docs/adr/0019-dependency-updates-and-supply-chain.md)).
